# Registration page design rationale

This revision keeps the original Ana illustrations, sunflower identity, video frame and slide ticket. The right-side registration column is 318px wide (290px at smaller desktop widths), with reduced form padding and a shorter event summary. It remains sticky on desktop and moves into the reading order on mobile.

The yellow proof strip sits above the bolder hero headline. Lesson sections use open layouts over sand, pale yellow and blush backgrounds. The gift uses a full-width yellow background and an illustrative exit-number worksheet. Testimonials share a pink section background; the closing recap uses dark ink. Removed the repeated outer cards, tape, thick shadows and oversized day badges. The actual workshop outputs receive the visual emphasis.
